# Rail · Le designer en 2030

Jeu web réalisé pour le cours **ICX3 · Designing for the Internet of Agents** (Master UX Design, UTC).

Vous êtes Harith, designer de design system en 2030. Une quarantaine d'agents fabriquent les écrans de Ligne, la plateforme de mobilité de la métropole de Lyon. Ils lisent vos règles à la lettre : à vous d'écrire des règles qu'ils ne peuvent pas mal interpréter.

**Jouer :** https://hafizh-yh.github.io/designer-2030/

Principes mobilisés : design tokens (W3C DTCG 2025.10), WCAG 2.2, RGAA 4.1.2, loi de Fitts, specification gaming.
Le document d'accompagnement (sources S01 à S27) est sur le board FigJam du projet.

Prototype · niveau 08:30 jouable.
